# Flutter Final Project

Mobile Application with Flutter

## Overview
This repository contains a mobile application built using the [Flutter](https://flutter.dev/) framework. The project demonstrates a cross-platform app leveraging Dart, C++, Swift, CMake, and other technologies.

## Features
- Cross-platform mobile support (iOS & Android)
- UI written in Dart using Flutter widgets
- Native integration with C++, Swift, and C

## Requirements
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart)
- Android Studio or Xcode (for platform-specific builds)

## Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Sorawit-loyde/Flutter_Final_project.git
   cd Flutter_Final_project
   ```

2. **Install dependencies:**
   ```sh
   flutter pub get
   ```

3. **Run the app:**
   - For Android:
     ```sh
     flutter run
     ```
   - For iOS:
     ```sh
     flutter run
     ```

## Setup

- Ensure you have Flutter installed and added to your PATH.
- For iOS development, install Xcode and set up CocoaPods.
- For Android, install Android Studio and configure an emulator/device.
